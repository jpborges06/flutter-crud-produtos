# formulario_nome (Exercícios 1 e 2)

- Nome obrigatório e com pelo menos 3 caracteres após `trim()`.
- Mensagens: `Informe o nome.` e `O nome deve ter pelo menos três caracteres.`
- A saudação só aparece após validação; se a entrada for inválida, a saudação anterior é apagada.
- Botão **Limpar**: apaga campo, saudação e mensagens de erro.

Testes sugeridos: vazio, dois espaços, `Al`, `Ana` (só `Ana` é aceita);
confirmar `Ana`, apagar e confirmar de novo (saudação some); provocar erro e clicar em Limpar.
