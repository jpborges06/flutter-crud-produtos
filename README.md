## Como executar

Cada pasta contém apenas o `lib/main.dart` e a documentação. Para rodar:

```bash
flutter create meu_projeto
# copie lib/main.dart da pasta desejada para meu_projeto/lib/main.dart
cd meu_projeto
flutter run
```

Apenas Flutter e Dart, sem pacotes adicionais.
